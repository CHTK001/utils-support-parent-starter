# utils-support-multipart-starter

utils-support-multipart-starter module

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-multipart-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `ApacheMultipartParser` | 基于 Apache Commons FileUpload2 的 multipart/form-data 解析器。 (SPI: `fileupload`) |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
