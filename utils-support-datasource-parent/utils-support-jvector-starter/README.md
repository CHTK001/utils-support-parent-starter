# utils-support-jvector-starter

JVector嵌入式向量数据库ORM

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-jvector-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `JVectorVectorStorage` | 基于 JVector 库实现的向量存储与检索服务。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
