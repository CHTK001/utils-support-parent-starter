# utils-support-milvus-starter

Milvus向量数据库ORM

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-milvus-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `MilvusVectorStorage` | 基于 Milvus 向量数据库的 实现。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
