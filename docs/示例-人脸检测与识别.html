人脸检测

FaceDetectExample 基础

使用 ScrFD、RetinaFace 等模型进行人脸检测，返回边界框和关键点。

FaceDetector detector = new FaceDetector("scrfd_2.5g_bnkps.onnx");
List<FaceDetection> faces = detector.detect("photo.jpg");
for (FaceDetection f : faces) {
    System.out.printf("位置: %d,%d,%d,%d  置信度: %.3f%n",
        f.getX(), f.getY(), f.getW(), f.getH(), f.getConfidence());
    System.out.println("关键点: " + f.getKeypoints());
}

人脸检测 + 绘制可视化，直接在图片上标注框和关键点，适合调试和展示。

多模型人脸检测对比：ScrFD + InsightFace + RetinaFace + UltraFace + TinaFace + ArcFace，支持多种检测器并行切换。

特征提取与比对

InsightFaceExample 推荐

使用 InsightFace ArcFace 模型提取 512 维人脸特征向量，支持相似度比对。

InsightFaceClient client = new InsightFaceClient("model.onnx");

// 提取特征
float[] feat1 = client.extract(face1Image);
float[] feat2 = client.extract(face2Image);

// 余弦相似度
float sim = cosine(feat1, feat2);
System.out.printf("相似度: %.4f %s%n", sim, sim > 0.6 ? "同一人" : "不同人");

// 批量比对
List<FaceRecord> known = loadFaceDatabase();
String matched = client.recognize(feat1, known, 0.6f);

活体检测

LivenessDiagExample 诊断

活体检测专项诊断工具，涵盖静默活体、动作活体等多种检测模式。

LivenessDetector detector = new LivenessDetector();

// 静默活体
boolean result = detector.checkStill(image);

// 动作活体（眨眼、摇头等）
boolean flowResult = detector.checkFlow(flowFrames);

System.out.println("活体检测结果: " + result);
