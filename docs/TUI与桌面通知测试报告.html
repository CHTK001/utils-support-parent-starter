3. TUI 使用说明

快速开始

```java
// 1. 添加依赖
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-tui-starter</artifactId>
    <version>${project.version}</version>
</dependency>

// 2. 构建仪表盘
TuiDashboard dashboard = TuiDashboardBuilder.create()
    .layout(TuiLayout.GRID_2x2)
    .title("系统监控仪表盘")
    .refreshInterval(2000L)
    .registerHandler(new SystemMonitorService())
    .addWidget(new CpuWidget("cpu", "CPU"))
    .addWidget(new MemoryWidget("memory", "内存"))
    .build();

// 3. 启动
dashboard.start();
dashboard.waitForExit();  // 按 q 退出，按 r 手动刷新
```

内置组件

组件类说明
CPU 监控CpuWidget显示 CPU 使用率进度条，自动变色
内存监控MemoryWidget显示内存使用率进度条
磁盘监控DiskWidget显示磁盘使用率
Htop 进程HtopWidget显示 Top 进程列表

自定义 Widget

```java
public class MyWidget extends TuiWidget {
    public MyWidget() { super("my_id", "My Widget"); }
    
    @Override
    public String render(String data) {
        return MordantHelper.panel(
            "Content: " + data, 
            getTitle(), 
            "single"
        );
    }
    
    @Override
    protected String getDefaultData() { return "default"; }
}
```

4. 桌面通知使用说明

快速开始

```java
// 1. 添加依赖
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-desktop-starter</artifactId>
    <version>${project.version}</version>
</dependency>

// 2. 发送通知
WindowsDesktopNotifier notifier = new WindowsDesktopNotifier();
notifier.notify("标题", "通知内容", null);  // icon 路径可选

// 或通过 DesktopPush (MessagePush SPI)
DesktopPush push = new DesktopPush();
MessageRequest req = new MessageRequest();
req.setSubject("标题");
req.setContent("内容");
push.send(req);
```
