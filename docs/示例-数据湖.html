数据湖：分布式数据存储与查询引擎，支持 SQL 查询、流式写入、订阅推送。

集成示例

DatalakeIntegratedExample 集成

数据湖完整集成示例：配置 → 建表 → 写入 → 查询 → 删除。

Datalake datalake = Datalake.builder()
    .storage("file", Path.of("./data/lake"))
    .build();

// 建表
datalake.createTable("users", schema -> schema
    .column("id", Type.LONG)
    .column("name", Type.STRING)
    .column("age", Type.INT)
);

// 写入
datalake.insert("users").row(1L, "张三", 25).execute();
datalake.insert("users").row(2L, "李四", 30).execute();

// 查询
List<Row> rows = datalake.select("users").where("age > ?", 20).execute();
