YOLO-World 开放词汇检测

YoloWorldExample 开放词汇

无需预训练类别即可检测任意物体，输入文本描述即可。

YoloWorldDetector detector = new YoloWorldDetector("damoyolo_visdrone.onnx");
List<DetectedObject> objects = detector.detect("image.jpg",
    new String[]{"person", "car", "building", "bird"});
objects.forEach(obj -> System.out.printf("%s: %.2f [%d,%d,%d,%d]%n",
    obj.getLabel(), obj.getConfidence(), obj.getBox()));
