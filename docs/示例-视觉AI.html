YOLO-World 开放词汇检测

YoloWorldExample 开放词汇

无需预训练类别即可检测任意物体，输入文本描述即可。

YoloWorldDetector detector = new YoloWorldDetector("damoyolo_visdrone.onnx");
List<DetectedObject> objects = detector.detect("image.jpg",
    new String[]{"person", "car", "building", "bird"});
objects.forEach(obj -> System.out.printf("%s: %.2f [%d,%d,%d,%d]%n",
    obj.getLabel(), obj.getConfidence(), obj.getBox()));

通用图片超分

能力入口：统一通过 ImageEnhancer（SPI 名称 onnx）调用，模型自动下载缓存。

Real-ESRGAN 通用 4x

真实照片通用超分（realesrgan_x4plus），任意图片放大 4 倍，兼顾锐化与细节重建。

// 直接按模型名创建
byte[] hd = ImageEnhancer.create("real-esrgan").enhance(ImageUtils.read(imageBytes));
// 或 SPI 方式：ImageEnhancer.create("onnx", key).model("real-esrgan").enhance(imageBytes)

Files.write(Path.of("output.png"), hd);

更多通用超分模型

以下模型同样可通过 ImageEnhancer 调用，适合不同场景。

// 4xNomos2 ESRGAN —— 高质量通用 4x 超分
byte[] a = ImageEnhancer.create("nomos2").enhance(imageBytes);

// 4xRealWebPhoto v4 —— 真实照片增强（去噪 + 超分）
byte[] b = ImageEnhancer.create("real-web-photo").enhance(imageBytes);

// waifu2x —— 动漫/二次元降噪放大
byte[] c = ImageEnhancer.create("waifu2x").enhance(imageBytes);

// SwinIR —— 去噪 / 超分
byte[] d = ImageEnhancer.create("swinir").enhance(imageBytes);

// 人脸专用：gfpgan / gfpgan-face-super-resolution / codeformer
byte[] e = ImageEnhancer.create("gfpgan").enhance(faceBytes);

模型清单 listModels()

ImageEnhancer.listModels() 按能力枚举全部已注册增强模型，供统一能力清单与前端筛选使用。

List<String> ids = ImageEnhancer.listModels();
// real-esrgan / nomos2 / real-web-photo / waifu2x / swinir / gfpgan / codeformer ...
