视频编解码

VideoCodecExample FFmpeg

FFmpeg 视频编解码：H264/H265/H266 编码与解码，支持 GPU 加速（NVENC/NVDEC）。

VideoCodec codec = VideoCodec.builder()
    .input("input.mp4")
    .codec("h264_nvenc")       // NVENC GPU 编码
    .resolution(1920, 1080)
    .fps(30)
    .output("output.mp4")
    .build();
codec.encode();
