文本嵌入 Embedding

前置依赖：pom.xml 中添加 utils-support-ai-starter 及对应模型 jar（如 utils-support-models-onnx-bge-small-zh）。

BGE 中文嵌入

BgeEmbeddingExample 离线

完全离线的文本向量化，模型随 jar 自动解压，无需下载。

try (EmbeddingClient client = EmbeddingClient.create(
        EmbeddingClientSetting.builder().provider("bge").build())) {
    String[] docs = {"你好世界", "今天天气很好", "人工智能正在改变世界"};
    float[][] vectors = client.model("bge-small-zh").embeddingBatch(docs);

    // 余弦相似度
    float sim = cosine(vectors[0], vectors[1]);
    System.out.println("相似度: " + sim);
}

BgeLargeZhEmbeddingExample

BGE-Large-ZH 更大模型，1024 维向量，精度更高但速度稍慢。

MiniLM 嵌入

MiniLmEmbeddingExample 轻量

MiniLM 轻量级嵌入模型，适合资源受限场景。

try (EmbeddingClient client = EmbeddingClient.create(
        EmbeddingClientSetting.builder().provider("minilm").build())) {
    float[] vector = client.model("minilm-l6-v2").embedding("查询文本");
    System.out.println("向量维度: " + vector.length); // 384 维
}

定价查询

ExampleModelPricingProvider

统一查询各模型计费信息，用于成本估算。

ModelPricingProvider provider = new ExampleModelPricingProvider();
ModelPrice price = provider.getPrice(AiModel.QWEN_MAX);
System.out.printf("输入: %.4f/百万token, 输出: %.4f/百万token%n",
    price.getInputPricePerMillion(), price.getOutputPricePerMillion());
