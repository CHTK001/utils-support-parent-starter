通义千问 Qwen Proxy

QwenProxyExample chat 零成本

通过 Playwright 驱动 Qwen 网页版，免费多轮对话、图像生成。无需 API Key，仅需 Cookie。

# 全部能力测试（对话+图像+视频）
java QwenProxyExample --cookie="token=eyJ..." --module=all

# 仅对话测试
java QwenProxyExample --cookie="token=xxx" --module=chat

# 仅图像生成测试
java QwenProxyExample --cookie="token=xxx" --module=image

核心 API（链式调用）

ChatClient client = ChatClient.create(
    ChatClientSetting.builder()
        .provider("qwen-proxy")
        .appKey("token=你的cookie")
        .model("qwen3.8-max")
        .build());

// 多轮对话（自动维护上下文）
String reply  = client.chatSync("我叫张三");
String recall = client.chatSync("我刚才说了什么？");
// recall 包含"张三"说明上下文有效

// 图像生成
ImageGenerationResult img = client.generateImage()
    .prompt("一只柯基犬在阳光下微笑")
    .ratio("16:9")
    .generate();
img.images().forEach(System.out::println);

client.close();
