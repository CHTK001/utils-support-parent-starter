HTTP 服务器

HttpServerExampleSpi Netty

基于 Netty 的高性能 HTTP 服务器，支持路由注册、中间件、异步响应。

// 链式构建服务器
Server server = ServerBuilder.newBuilder()
    .port(8080)
    .addRoute("GET", "/api/hello", ctx -> ctx.json(Map.of("msg", "hello")))
    .addRoute("POST", "/api/data", ctx -> {
        String body = ctx.body();
        return Results.json(Map.of("echo", body));
    })
    .build();
server.start();

代理服务器

Socks5ProxyExampleSpi SOCKS5

SOCKS5 代理服务器，支持 UDP associate、认证（用户名/密码）、转发任意 TCP 连接。

Socks5ProxyServer proxy = Socks5ProxyServer.builder()
    .port(1080)
    .auth(new UsernamePasswordAuth("user", "pass"))
    .build();
proxy.start();

RPC 远程调用

RpcExample / TcpRpcExampleSpi RPC

TCP 序列化 RPC 框架，支持注解服务注册、动态代理客户端、负载均衡。

// 服务端注册
@RpcService
public class EchoServiceImpl implements EchoService {
    @Override public String echo(String msg) { return "echo: " + msg; }
}

// 客户端调用（链式）
EchoService client = RpcClient.builder()
    .target("127.0.0.1:9090")
    .service(EchoService.class)
    .build();
String result = client.echo("hello");

MQTT 消息队列

MqttServerExampleSpi MQTT

轻量级 MQTT Broker，支持 QoS 0/1/2、订阅/发布、遗嘱消息、retaining message。

MqttServer mqtt = MqttServer.builder()
    .port(1883)
    .addHandler("sensor/#", (topic, payload) -> {
        System.out.println("收到: " + new String(payload));
    })
    .build();
mqtt.start();

Scatter 对等网格

ScatterClusterExampleSpi / ScatterNodeMain

Scatter 是无中心化对等网格框架，支持 seed 引导发现、网关模式、故障退避、一致哈希路由。

Scatter scatter = Scatter.builder()
    .scatterId("order")
    .seeds("192.168.1.10:19001")
    .gateway(true)
    .build();
scatter.start();
