版面分析

LayoutPipelineExample DocLayout-YOLO

基于 DocLayout-YOLO 的文档版面分析，识别标题、段落、表格、图片等区域。

DocLayoutAnalyzer analyzer = new DocLayoutAnalyzer("doclayout-yolo.onnx");
LayoutResult result = analyzer.analyze("document.pdf");
for (LayoutBlock block : result.getBlocks()) {
    System.out.printf("%s: [%d,%d,%d,%d] conf=%.2f%n",
        block.getType(), block.getX(), block.getY(),
        block.getW(), block.getH(), block.getConfidence());
}
