TUI：基于 Terminal 的交互式仪表盘，类似 htop 的终端监控工具。

TUI 仪表盘

TuiDashboardExample 仪表盘

终端仪表盘：CPU/内存/磁盘实时监控，类 htop 界面。

TuiDashboard dashboard = TuiDashboard.builder()
    .widget(new CpuWidget())
    .widget(new MemoryWidget())
    .widget(new DiskWidget())
    .widget(new HtopWidget())
    .refreshInterval(1000)  // 1秒刷新
    .build();
dashboard.start();
