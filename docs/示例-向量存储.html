jvector 本地库

VectorStorageExampleSpi 本地

jvector 纯 Java 向量库，无需外部依赖，适合嵌入式部署。

VectorStorage storage = VectorStorage.builder()
    .provider("jvector")
    .dimension(512)
    .indexType(IndexType.HNSW)
    .build();

// 添加向量
storage.add("doc1", new float[]{0.1f, 0.2f, ...});

// 相似度搜索
List<VectorResult> results = storage.search(new float[]{0.15f, 0.18f, ...}, 5);
for (VectorResult r : results) {
    System.out.printf("%s: %.4f%n", r.getId(), r.getScore());
}
