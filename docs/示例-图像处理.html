图像滤镜（SPI 插件化）

ImageProcessorSpiExample SPI

通过 SPI 注册自定义滤镜，自动发现并加载。

@Spi("ClayStyle")
@SpiDescribe("clay 风格滤镜")
public class ClayStyleImageFilter extends AbstractImageFilter {
    @Override
    public BufferedImage filter(BufferedImage src, BufferedImage dst) {
        // 实现滤波逻辑
        return dst;
    }
}

基础滤镜

ImageProcessorSpiExample / CustomImageProcessor

高斯模糊、灰度、阈值、边缘检测等常用滤镜。

ImageProcessor processor = ImageProcessor.builder()
    .filter(new GaussianBlurFilter(3))
    .filter(new GrayFilter())
    .filter(new EdgeDetectFilter())
    .build();
BufferedImage result = processor.process(inputImage);

ImageSobelFilter / ImageGaussianBlurFilter / ImageBrightImageFilter

Sobel 边缘、高斯模糊、亮度增强等基础滤镜的独立示例。

清晰度检测

ImageClarityDetectorExample 清晰度

基于拉普拉斯方差和 Tenengrad 算法，自动判断图像是否清晰。

ImageClarityDetector detector = new ImageClarityDetector();
ClarityResult result = detector.detect(image);
System.out.printf("清晰度: %.2f %s%n", result.getScore(),
    result.isClear() ? "清晰" : "模糊");
