四、关键实现说明

  • SQL → 词法(TokenStream) → 二叉表达式树 AST（MemorySqlAst：BinaryNode/InNode/BetweenNode/LikeNode…）→ 在 dataStores 的 List 行引用上执行 filter/sort/skip/limit/project 管道
  • ? 参数按行重置游标绑定（绑定值不随行变化）；INSERT/SET 解析期静态消费，WHERE 求值期逐行独立消费
  • 行形态双兼容：Map（忽略大小写）与 bean（getter/setter 反射已 setAccessible 放开包私有类）
  • DML 直接作用于 list 引用（add/set/removeIf），SQL 与 Lambda 查询共享同一 dataStores
