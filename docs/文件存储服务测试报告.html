五、本轮缺陷发现与修复记录（7 项）

#缺陷根因修复方式
1FileSystemFileStorage 无法通过 SPI 创建（工厂返回 null）缺失 META-INF/extensions/com.chua.common.support.storage.FileStorage 注册文件（各云厂商实现均有，唯独本地实现遗漏）补充注册文件（utils-support-filesystem-starter）
2FileStorageServerFilter 为空壳（仅透传）doFilter 未实现任何存储逻辑，storageMap 注册后从未使用补全完整 REST 实现（CRUD/目录/Range/水印/安全），并实现 ReactiveServerFilter 接入响应式过滤链
3子目录列表永远为空LocalFileStorage.listObject 硬编码返回空集合补全 Files.list 目录扫描实现
4中文文件名下载返回 500Content-Disposition 直接写入非 ASCII 字符，JDK HttpServer 校验非法响应头按 RFC 5987 追加 filename*=UTF-8'' 编码形式并保留 ASCII 回退
5开启 openRemoteFile 后远程地址仍被拒绝 400框架返回的路径已解码，http:// 被拆散成多段后命中冒号穿越校验doFilter 增加 http:/ https:/ 前缀识别与地址重组
6远程拉取稳定 502URL.openStream() 走系统代理，内网地址被代理拦截HttpURLConnection + Proxy.NO_PROXY 直连，并设置超时
7前端跨域访问全部失败（阻断级）框架内置 CorsFilter 为阻塞式过滤器，不在实际生效的响应式过滤链中，CORS 头与 OPTIONS 预检均无人处理FileStorageServerFilter 自足处理：统一追加 CORS 响应头 + OPTIONS 预检直接 204 放行

六、REST API 参考

接口说明
GET /{bucket}根目录对象列表（JSON：bucket/path/count/items[]，item 含 name/size/directory/lastModified）
GET /{bucket}/{dirPath}子目录列表（目录 Key 自动回退列表）；尾斜杠表示显式目录语义，不存在时返回空列表而非 404
GET /{bucket}/{key}下载/预览对象；默认 inline（openPreview），?download=true 强制附件（openDownload）；支持 Range 分段（openRange）返回 206
HEAD /{bucket}/{key}存在性检查（200 / 404）
PUT|POST /{bucket}/{key}上传对象，body 为原始文件内容，自动创建父级目录
DELETE /{bucket}/{key}删除对象（幂等）
OPTIONS 任意路径CORS 预检，204 放行
启动方式：run-filestorage.bat [端口]（spring-support-parent-starter 根目录）  ·   前端入口：文件系统 → 文件存储服务（/filesystem/filestorage）  ·   本报告由自动化脚本与集成测试共同产出
