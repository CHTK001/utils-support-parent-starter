六、本轮缺陷发现与修复记录（8 项）

#缺陷根因修复方式
1FileSystemFileStorage 无法通过 SPI 创建（工厂返回 null）缺失 META-INF/extensions 注册文件补充注册文件
2FileStorageServerFilter 为空壳（仅透传）doFilter 未实现存储逻辑补全完整 REST 实现 + ReactiveServerFilter 接入响应式链
3子目录列表永远为空LocalFileStorage.listObject 硬编码空集合补全 Files.list 目录扫描
4中文文件名下载 500Content-Disposition 非 ASCII 非法头RFC 5987 filename*=UTF-8'' 编码
5openRemoteFile 开启后仍拒绝远程地址 400框架路径已解码，http:// 被拆散命中冒号校验http:/ https:/ 前缀识别与地址重组
6远程拉取稳定 502URL.openStream() 走系统代理拦截内网地址Proxy.NO_PROXY 直连 + 超时
7前端跨域访问全部失败（阻断级）内置 CorsFilter 为阻塞式过滤器，不在生效的响应式链中Filter 自足处理 CORS 头 + OPTIONS 预检 204
8SPI 预览 xlsx/docx 失败（返回原始字节）commons-compress 为 filestorage-starter 的传递依赖，未显式引入导致运行时缺失显式声明 commons-compress 1.28.0 + 重建 fs-args.txt 恢复模块输出目录

七、查询参数与启动方式

参数语义（标志式，存在即开启）
?preview强制内联预览（= true / =1 等价；=false / =0 显式关闭）；受 openPreview 开关约束；触发 SPI 预览（xlsx/docx/pptx 等 Office 文档转 HTML）
?download强制附件下载；受 openDownload 开关约束
Range 头bytes=start-end 区间 / bytes=-N 后缀；越界或非法降级全量 200；受 openRange 开关约束

启动：spring-support-parent-starter\run-filestorage.bat [端口]（默认 18080）。前端入口：文件系统 → 文件存储服务（/filesystem/filestorage）。
