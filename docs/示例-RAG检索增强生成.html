RAG 检索增强生成

RAG 完整流程：文档上传 → 自动切片 → 向量嵌入 → 语义检索 → LLM 生成答案。支持 PDF/DOCX/TXT/MD/XLSX/CSV。

命令行用法

RagChatExample 完整流程

# 上传文档（内存 provider，无需外部服务）
java RagChatExample upload --provider=memory --file=manual.pdf

# 使用 OpenAI 兼容接口
java RagChatExample upload --provider=openai --key=sk-xxx --file=guide.pdf

# 文档问答
java RagChatExample query --provider=memory --q="如何使用 XX 功能？" --topK=3

# 仅向量召回（不调 LLM）
java RagChatExample search --q="分布式锁"

# 文档管理
java RagChatExample list
java RagChatExample delete --id=xxx
java RagChatExample reindex

API 文档管理

核心接口

方法说明
uploadDocument(fileName, data)上传文档，返回含 fileId 的 RagDocument
updateDocument(docId, fileName, data)保留原 docId 更新内容并重新索引
deleteDocument(docId)同步清理向量存储和落盘文件
readDocumentContent(docId)读取原始文本内容
listDocuments(page, pageSize)分页查询文档列表
reindex()重新向量化所有 READY 文档

编程式调用

完整示例

RagClient rag = RagClient.create("memory", RagClientSetting.builder()
    .embeddingClient(embedding)
    .chatClient(chat)
    .vectorStorage(storage)
    .topK(3)
    .build());

// 上传 → 返回含 fileId 的 RagDocument
RagDocument doc = rag.uploadDocument("manual.pdf", pdfBytes);
String fileId = doc.id();

// 更新文档（保留原 fileId）
rag.updateDocument(fileId, "manual-v2.pdf", newPdfBytes);

// 删除（同步清理向量+文件）
rag.deleteDocument(fileId);

// 读取原文
String content = rag.readDocumentContent(fileId);

// 查询
RagResponse resp = rag.query("XX 功能怎么用？");
System.out.println(resp.answer());
resp.sources().forEach(s -> System.out.println("引用: " + s.content()));

UploadProvider SPI

上传策略可切换：通过 RagClient.UploadProvider SPI 接口实现不同存储后端。

自定义云存储上传

@Spi("s3")
public class S3UploadProvider implements RagClient.UploadProvider {
    @Override
    public String upload(String docId, String fileName, byte[] data) {
        return s3Client.putObject(bucket, docId + "_" + fileName, data);
    }
    @Override
    public byte[] read(String fileId) { return s3Client.getObject(fileId); }
    @Override
    public boolean delete(String fileId) { return s3Client.delete(fileId); }
}
