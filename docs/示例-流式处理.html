OffsetFlow 偏移流

OffsetFlowExample 基础

带偏移量的流式处理，支持断点续传和位置恢复。

OffsetFlow<String> flow = OffsetFlow.builder()
    .source(() -> generateData())
    .processor(data -> processData(data))
    .offsetStore(new FileOffsetStore("./offset.dat"))
    .batchSize(100)
    .build();
flow.start();
