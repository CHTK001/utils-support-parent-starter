分割模型：SAM、DepthAnything、SegAny、边缘检测分割等。

SAM 分割

SegmentationExample SAM

Segment Anything Model (SAM) 零样本分割，支持点提示和框提示。

SamSegmenter segmenter = new SamSegmenter("sam_vit_b_01ec64.onnx");

// 点提示分割
List<Mask> masks = segmenter.segment(image)
    .withPointPrompt(320, 240)   // x, y
    .execute();

// 框提示分割
List<Mask> masks = segmenter.segment(image)
    .withBoxPrompt(100, 100, 400, 400)  // x1,y1,x2,y2
    .execute();

深度估计

DepthAnythingVerify / DepthAnythingOrtVerify

Depth Anything 单目深度估计，从单张图片恢复深度信息，支持 ONNX 和 ORT 格式。

EdgeSamExample

结合边缘检测与 SAM 的分割方案，先检测物体边缘再进行精细分割。
