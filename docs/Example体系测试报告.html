四、JDK 25 环境要求记录

  • --enable-preview：common-starter 以 preview 特性编译（class file 69.65535），运行必须携带。
  • --add-opens java.base/java.lang=ALL-UNNAMED 等：JsonSerializer/ModuleLoader 需要深反射打开 java.base 模块，否则报 InaccessibleObjectException。加上后 9 种序列化实现 18/18 全部 [OK]。
  • JEP 467：javac 默认不再启用注解处理器，单独编译 lombok 类需显式 -proc:full。
  • 国密 SM3：JDK 无内置 MessageDigest，DigestUtils.sm3() 需引入 BouncyCastle。
