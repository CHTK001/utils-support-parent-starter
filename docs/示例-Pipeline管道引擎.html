Pipeline 管道引擎

示例包：com.chua.example.pipeline · SPI 插件化管道编排

← 返回文档中心
Pipeline 引擎：支持串行、并行、条件分支、重试、WAL 持久化等多种管道模式，每个节点独立 SPI 注册，可热插拔。

基础管道（链式调用）

PipelineBasicExample 基础

最简单的管道：A → B → C 串行执行，每一步的输出作为下一步的输入。

// 链式构建
Pipeline pipeline = PipelineBuilder.newBuilder("my-pipeline")
    .task("step1", ctx -> {
        ctx.setData("result", "A执行完毕");
        return null;
    }).taskEnd()
    .task("step2", ctx -> {
        String prev = ctx.getData("result");
        ctx.setData("result", prev + " + B执行");
        return null;
    }).taskEnd()
    .task("step3", ctx -> {
        String result = ctx.getData("result");
        System.out.println("最终结果: " + result);
        return null;
    }).taskEnd()
    .build();

pipeline.execute(new PipelineContext());

onStep 回调

PipelineOnStepExample

无返回值的步骤（Consumer 模式），通过 onStep 监听每一步执行。

Pipeline pipeline = PipelineBuilder.newBuilder("pipeline-with-callback")
    .task("step1", ctx -> {
        System.out.println("执行 step1");
        return null;
    }).taskEnd()
    .onStep(ctx -> System.out.println("任意步骤执行后回调: " + ctx.getCurrentStep()))
    .build();

exit 停止

PipelineExitExample

某一步返回 false 时自动停止后续步骤，适合流水线短路场景。

Pipeline pipeline = PipelineBuilder.newBuilder("short-circuit")
    .task("check", ctx -> {
        if (!validate(ctx.getData("input"))) return false;
        return true;
    }).taskEnd()
    .task("process", ctx -> { /* 只有 check 通过才执行 */ })
    .taskEnd()
    .build();

指定起始节点

PipelineStartExample

从指定节点开始执行，适合动态路由和按需加载。

Pipeline pipeline = PipelineBuilder.newBuilder("partial-start")
    .task("step1", ctx -> { /* 跳过 */ return null; }).taskEnd()
    .task("step2", ctx -> { /* 实际开始 */ return null; }).taskEnd()
    .task("step3", ctx -> { return null; }).taskEnd()
    .startFrom("step2")   // 从 step2 开始
    .build();

并行管道

PipelineParallelExample 并行

多个节点并行执行，全部完成后汇聚结果，适合 I/O 密集型任务。

Pipeline pipeline = PipelineBuilder.newBuilder("parallel")
    .parallel("branch1", builder -> builder
        .task("fetch-a", ctx -> fetchData("A")).taskEnd()
        .task("fetch-b", ctx -> fetchData("B")).taskEnd()
    )
    .task("merge", ctx -> mergeResults(ctx))
    .build();

条件分支

PipelineDecisionExample 决策

根据前一步结果动态选择后续分支，支持 if/else 多路分支。

重试机制

PipelineRetryExample 重试

节点失败后自动重试，支持指数退避、最大次数限制、自定义重试策略。

Pipeline pipeline = PipelineBuilder.newBuilder("retry-demo")
    .task("unstable-api", ctx -> callUnstableApi())
    .retry(3)                    // 最多重试3次
    .retryBackoff(1000, 2.0)     // 指数退避：1s, 2s, 4s
    .build();

WAL 持久化

PipelineWalExample WAL

写前日志（Write-Ahead Log）保证管道崩溃后可恢复，断电不丢数据。

人脸编排

PipelineFaceOrchestrationExample 人脸

人脸检测 → 对齐 → 特征提取 → 比对的完整 Pipeline 编排示例。

Pipeline pipeline = PipelineBuilder.newBuilder("face-chain")
    .task("detect", ctx -> detectFaces(ctx.getImage()))
    .task("align",  ctx -> alignFaces(ctx.getFaces()))
    .task("embed",  ctx -> extractFeatures(ctx.getAligned()))
    .task("compare",ctx -> matchAgainstDatabase(ctx.getFeatures()))
    .build();
