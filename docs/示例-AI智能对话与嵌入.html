通义千问对话（QwenProxy）

QwenProxyExample chat 零成本

通过 Playwright 驱动 Qwen 网页版，实现免费多轮对话、图像生成与视频生成。无需 API Key，仅需 Cookie。

java QwenProxyExample --cookie="token=eyJ..." --module=all

# 只测试对话
java QwenProxyExample --cookie="token=xxx" --module=chat

# 只测试图像生成
java QwenProxyExample --cookie="token=xxx" --module=image

核心 API（链式调用）

// 创建客户端
ChatClient client = ChatClient.create(
    ChatClientSetting.builder()
        .provider("qwen-proxy")
        .appKey("token=你的cookie")
        .model("qwen3.8-max")
        .build());

// 多轮对话（自动维护上下文）
String reply = client.chatSync("我叫张三");
String recall = client.chatSync("我刚才说了什么？");  // 包含"张三"说明上下文有效

// 图像生成（链式）
ImageGenerationResult img = client.generateImage()
    .prompt("一只柯基犬在阳光下微笑")
    .ratio("16:9")
    .generate();

client.close();

文本嵌入 Embedding

BgeEmbeddingExample / MiniLmEmbeddingExample 离线

完全离线的文本向量化工具，支持 BGE、MiniLM 等多种模型，模型随 jar 自动解压。

// BGE 中文嵌入（离线）
try (EmbeddingClient client = EmbeddingClient.create(
        EmbeddingClientSetting.builder().provider("bge").build())) {
    String[] docs = {"你好世界", "今天天气很好", "人工智能正在改变世界"};
    float[][] vectors = client.model("bge-small-zh").embeddingBatch(docs);

    // 余弦相似度
    float sim = cosine(vectors[0], vectors[1]);
    System.out.println("相似度: " + sim);
}

BgeLargeZhEmbeddingExample

使用更大的 BGE-Large-ZH 模型，精度更高但速度稍慢，适合对准确度要求高的场景。

RAG 检索增强生成

RagChatExample 完整流程

文档上传 → 自动切片 → 向量嵌入 → 语义检索 → LLM 生成答案。支持 PDF/DOCX/TXT/MD/XLSX/CSV。

# 上传文档（使用内存 provider，无需外部服务）
java RagChatExample upload --provider=memory --file=manual.pdf

# 上传并使用 OpenAI 兼容接口
java RagChatExample upload --provider=openai --key=sk-xxx --file=guide.pdf

# 文档问答
java RagChatExample query --provider=memory --q="如何使用 XX 功能？" --topK=3

# 仅向量召回（不调 LLM）
java RagChatExample search --q="分布式锁"

# 文档管理
java RagChatExample list
java RagChatExample delete --id=xxx
java RagChatExample reindex
文档管理 API：
uploadDocument(fileName, data) → 返回 RagDocument，含 id（即 fileId）
updateDocument(docId, fileName, data) → 保留原 docId 更新内容并重新索引
deleteDocument(docId) → 同步清理向量和落盘文件
readDocumentContent(docId) → 读取原始内容
listDocuments(page, pageSize) → 分页列表
reindex() → 重新向量化所有 READY 文档

编程式调用（链式）

RagClient rag = RagClient.create("memory", RagClientSetting.builder()
    .embeddingClient(embeddingClient)
    .chatClient(chatClient)
    .vectorStorage(vectorStorage)
    .topK(3)
    .build());

// 上传 → 返回含 fileId 的 RagDocument
RagDocument doc = rag.uploadDocument("manual.pdf", pdfBytes);
String fileId = doc.id();

// 更新文档（保留原 fileId）
rag.updateDocument(fileId, "manual-v2.pdf", newPdfBytes);

// 删除（同步清理向量+文件）
rag.deleteDocument(fileId);

// 读取原文
String content = rag.readDocumentContent(fileId);

// 查询
RagResponse resp = rag.query("XX 功能怎么用？");
System.out.println(resp.answer());
System.out.println("引用: " + resp.sources());

语音识别与合成

WhisperAudioExample STT

OpenAI Whisper 大模型语音转文字，支持中英文混合识别。

WhisperClient whisper = new WhisperClient(WhisperModel.LARGE_V3);
AudioTranscript transcript = whisper.transcribe("audio.wav");
System.out.println(transcript.getText());
for (Segment seg : transcript.getSegments()) {
    System.out.printf("[%.2fs-%.2fs] %s%n", seg.getStart(), seg.getEnd(), seg.getText());
}

PocketTtsVoiceCloneExample TTS 轻量

轻量级 TTS 引擎，支持声音克隆，适合嵌入式部署场景。

PocketTts tts = new PocketTts();
tts.voice("zh-CN-XiaoxiaoNeural")
   .speed(1.0f);
tts.synthesize("你好，欢迎使用语音合成服务", "output.wav");

视觉 AI

YoloWorldExample / OpenVocabularyDetectionExample

YOLO-World 开放词汇目标检测，无需预训练类别即可检测任意物体。

YoloWorldDetector detector = new YoloWorldDetector("damoyolo_visdrone.onnx");
List<DetectedObject> objects = detector.detect(
    "image.jpg",
    new String[]{"person", "car", "building", "bird"});
for (DetectedObject obj : objects) {
    System.out.printf("%s: %.2f [%d,%d,%d,%d]%n",
        obj.getLabel(), obj.getConfidence(), obj.getBox());
}

System.out.printf("输入: %.4f/百万token, 输出: %.4f/百万token%n",
