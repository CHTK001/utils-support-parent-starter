TableViewParser 无边框模式 测试报告

模块：utils-support-common-starter · 包：com.chua.common.support.lang.view · 验证入口：com.chua.example.lang.TableViewParserExample · 执行日期：2026-08-24

一、功能说明

TableViewParser 新增实例属性 borderless（默认 false，行为完全兼容）， 通过链式方法 setBorderless(boolean) 开启后，表格渲染不绘制任何框线字符（┌ ─ ├ │ 等）， 仅按列宽以空格对齐，行尾不含多余空白；适用于日志输出与窄屏终端。

new TableViewParser().setBorderless(true).render(data)

Key  Value          <- 表头与数据行仅空格对齐
foo  123            <- 无任何框线字符
bar  456

覆盖路径：Map 两列、List<Map> 动态列、POJO 列表、简单类型单列四条渲染链路均生效； 空数据仍返回占位文本 (empty)。

四、实现要点备查

  • 属性为实例字段并配套链式 setter，SPI 注册路径行为零变化；
  • 私有渲染方法由 static 调整为实例方法以读取状态，纯绘制辅助（hLine/appendRow/padRow）保持 static；
  • 新增 renderWithoutBorder/plainRow 私有辅助，行尾统一 stripTrailing()。
