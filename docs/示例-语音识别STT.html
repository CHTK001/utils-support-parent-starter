四、Zipformer-zh 新引擎详情（2026-09-01）

ZipformerZhAudioClient 嵌入式 纯中文 小模型

基于 sherpa-onnx Zipformer-zh-14M 的轻量级中文 ASR 引擎，模型仅 16MB，适合资源受限场景。

// 嵌入式模型（内置于 JAR，自动解压缓存到 %TEMP%）
String text = ZipformerZhAudioClient.create()
    .transcribe(Path.of("chinese.wav"));

// 支持 HF 仓库兜底（模型不存在于 JAR 时自动从 HuggingFace 下载）
ZipformerZhAudioClient.create()
    .hfRepo("chtk/sherpa-onnx-zipformer-zh-14M")
    .transcribe(Path.of("audio.wav"));

流式转录 API（feedAudio / getResult / complete） 新增

VirtualClient 接口新增流式方法，支持 chunk-by-chunk 喂入音频数据：

// 流式喂入 160ms 片段（2560 samples @ 16kHz）
VirtualClient client = VirtualClient.create("zipformer-zh-streaming");
float[] chunk = new float[2560];
// ... 填充 chunk ...
client.feedAudio(chunk);   // 喂入音频块
// ... 继续喂入 ...
String partial = client.getResult();  // 获取当前部分结果
client.complete();            // 标记结束，获取最终结果
String finalResult = client.getResult();

八、API 使用示例

语音识别管线

// 基础用法
String text = AsrPipeline.builder("paraformer-zh-small")
    .build().transcribe(Path.of("audio.wav"));

// 全管线：降噪 + VAD 切分 + 后处理
String text = AsrPipeline.builder("sensevoice")
    .language("zh")
    .vad(true)
    .denoise(true)
    .postProcess(true)
    .build()
    .transcribe(Path.of("chinese.wav"));

// Zipformer-zh（轻量嵌入式）
String text = ZipformerZhAudioClient.create()
    .transcribe(Path.of("audio.wav"));

// 流式转录
VirtualClient client = VirtualClient.create("zipformer-zh-streaming");
client.feedAudio(chunk1);
client.feedAudio(chunk2);
String partial = client.getResult();
client.complete();
String finalResult = client.getResult();

声纹引擎

VoiceprintPipeline vp = VoiceprintPipeline.create();

// 登记
vp.enroll("alice", Path.of("alice-enroll.wav"));

// 1:N 检索
List<Match> top = vp.search(Path.of("query.wav"), 3);
for (Match m : top) {
    System.out.println(m.speakerId() + " -> " + m.similarity());
}

// 1:1 验证（取 search(1) 的结果，判断 id 即可）
List<Match> result = vp.search(Path.of("test.wav"), 1);
boolean isAlice = !result.isEmpty()
    && result.get(0).speakerId().equals("alice")
    && result.get(0).similarity() > 0.7;

OpenAI 标准 STT OpenAI 标准 SPI

基于 OpenAI 音频标准接口 POST /v1/audio/transcriptions 的 VirtualClient 实现，支持 OpenAI 兼容服务商（openai / openai-asr / siliconflow / sensetime / github / gitee）。

// 前置依赖：utils-support-openai-starter
String text = VirtualClient.create("openai", "sk-xxx")
    .model("whisper-1")           // whisper-1 / gpt-4o-transcribe / gpt-4o-mini-transcribe
    .language("zh")               // 可选 ISO 639-1
    .prompt("补充上下文提示")       // 可选：提升特定词汇识别
    .transcribe(Path.of("audio.wav"));

// 自定义地址 + 代理（对接 b.ai 等 OpenAI 兼容网关）
String text = VirtualClient.create("openai", "sk-xxx", "https://api.b.ai/v1")
    .model("whisper-1")
    .transcribe(Path.of("audio.mp3"));

模型清单 models()

VirtualClient 通过 models() / listModels() 暴露标准 ASR 模型，供统一能力清单与前端筛选使用。

List<ModelDefinition> defs = VirtualClient.create("openai", "sk-xxx").models();
List<String> ids = VirtualClient.create("openai", "sk-xxx").listModels();
// whisper-1 / gpt-4o-transcribe / gpt-4o-mini-transcribe
