Whisper 语音转文字

WhisperAudioExample OpenAI

OpenAI Whisper 大模型语音转文字，支持中英文混合识别。

WhisperClient whisper = new WhisperClient(WhisperModel.LARGE_V3);
AudioTranscript transcript = whisper.transcribe("audio.wav");
System.out.println(transcript.getText());

// 带时间戳的逐段输出
transcript.getSegments().forEach(s ->
    System.out.printf("[%.2fs-%.2fs] %s%n", s.getStart(), s.getEnd(), s.getText()));
