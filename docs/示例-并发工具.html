并发工具：无锁队列、持久化队列、共享内存队列、惰性过期列表。

LockFreeQueue

LockFreeQueueExample 无锁

基于 CAS 的无锁队列，支持多线程高并发生产消费。

LockFreeQueue<String> queue = new LockFreeQueue<>(1024);
queue.offer("item-1");
queue.offer("item-2");
String item = queue.poll();

PersistentLockFreeQueue

PersistentLockFreeQueueExample 持久化

无锁队列 + 磁盘持久化，进程重启后数据不丢失。

ShmQueue 共享内存队列

ShmQueueExample 共享内存

跨进程共享内存队列，适合进程间通信场景，零拷贝高性能。
