分析

MemoryVectorStorage：搜索延迟最低（9–13us），写入吞吐最高（201万条/s euclidean），适合 ≤10万向量纯内存场景。
DefaultVectorStorage HYBRID：写入吞吐接近 memory（50–72万条/s），搜索延迟 198–280us。适合持久化+冷热混合场景，冷数据量不大时表现良好。
JVectorVectorStorage：启用 Panama Vector API 后图索引正常工作。5K 规模下图构建开销仍高于线性扫描（113ms vs 56ms），建议 100K+ 规模才能体现图索引优势。
