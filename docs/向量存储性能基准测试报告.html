推荐选型

纯内存场景（≤100K 向量）：使用 MemoryVectorStorage 或 DefaultVectorStorage(MEMORY)，搜索延迟最低（<20us），写入吞吐最高（>50万条/s）。
持久化场景（冷数据盘存储）：使用 DefaultVectorStorage(HYBRID)，B+Tree 索引 + MappedByteBuffer 零拷贝，支持冷热混合，但搜索延迟较高（>200us）。
JVector GPU/图搜索：当前 JDK 25 环境下 jdk.incubator.vector 模块不可读，GraphSearcher 会降级为 brute-force，需升级到支持 Vector API 的 JDK 版本或传递 --add-modules jdk.incubator.vector 后才能发挥图索引优势。
