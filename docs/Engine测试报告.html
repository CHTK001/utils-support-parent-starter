四、本轮测试发现并修复的缺陷

#缺陷位置修复
1 ReflectUtils.instantiate(Class) 永远返回 null：(T) handle.invokeExact() 在泛型擦除后调用点签名为 ()Object，与构造器句柄类型不匹配必然抛 WrongMethodTypeException 且被静默吞掉。影响所有依赖无参实例化的行映射场景。 common-starter
ReflectUtils.java:432		 改为 clazz.cast(handle.invoke())；同模式修复 asFunctionalInterface
2 H2 大写列名映射失败：H2/Oracle 返回大写列名 NAME，setFieldValue 仅尝试原名与驼峰，字段 name 匹配不到。 JdbcReactorEngine
setFieldValue		 候选列表增加小写形式 columnName.toLowerCase() 及其驼峰变体
3 r2dbc-mysql 批量部分执行后降级冲突：R2DBC batch 部分写入成功后抛 ClassCastException，降级 JDBC 重放引发主键 Duplicate entry。 JdbcReactorEngine
batchViaR2dbc		 MySQL/MariaDB 批量直接路由 JDBC（needsJdbcPath），避免重放
4 batchViaJdbc 逐批发射语义不一致：返回 updates 数组逐项发射，与「总行数」契约不符。 JdbcReactorEngine
batchViaJdbc		 统一求和后单值发射 Flux.just(total)
5 POM 合并冲突残留：onnx-starter 与 example-starter 的 pom.xml 存在 <<<<<<</=======/>>>>>>> 标记导致整个 reactor 无法构建。 utils-support-deeplearning-onnx-starter
utils-support-example-starter		 按现存模块解析冲突（保留 whisper/moonshine；includes 取并集）
