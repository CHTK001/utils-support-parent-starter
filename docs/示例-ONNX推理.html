Seq2Seq 文本生成

Seq2SeqExample / Seq2SeqTranslationTest

mT5、T5、BART 等 Seq2Seq 模型的中文翻译与文本生成。

Seq2SeqTranslator translator = new T5BaseSeq2SeqOrtTranslator("model.onnx");
String result = translator.translate("Hello, how are you?", "zh");
System.out.println("译文: " + result);

车牌识别

Yolo5PlateDetectOnnxTranslator / Yolo5PlateRecTranslator

YOLOv5 车牌检测 + CRNN 车牌识别，端到端车牌号码提取。

PlateDetector detector = new Yolo5PlateDetectOnnxTranslator("plate-detect.onnx");
PlateRecognizer recognizer = new Yolo5PlateRecTranslator("plate-rec.onnx");

List<PlateResult> results = detector.detect("traffic.jpg")
    .stream()
    .map(box -> recognizer.recognize(crop(box)))
    .toList();
