SIP 内网穿透工具使用说明

基于信令服务器的内网穿透隧道工具。双模式自动选择（直连 / 中继），支持端口映射与 SOCKS5 代理。

1. 架构

SIP 通信架构 — 信令与数据平面分离
1

信令连接

Provider / Visitor 均与 SipServer 建立长连接，收发认证/注册/隧道命令

2

隧道建立

Visitor 请求 OPEN → SipServer 路由到 Provider → 双方收到通道 ID

3

直连尝试

Visitor 获得 Provider 地址，尝试直接 TCP 连接（走内网或公网）

4

中继兜底

直连失败 → 双方通过 SipServer 桥接数据，不中断隧道

双模式自动选择：数据连接先尝试直连，失败自动回退服务器中继，无需配置，天生双模式。

2. SipServer（信令服务器）

2.1 编程启动

// 默认配置（0.0.0.0:19460）
SipServer server = new SipServer();
server.start();

// 自定义配置
SipConfig config = SipConfig.builder()
        .host("0.0.0.0")
        .port(19460)
        .token("my-secret")
        .build();
SipServer server = new SipServer(config);
server.start();

2.2 运行时控制

int port = server.getPort();                          // 实际监听端口
List<String> clients = server.getConnectedClients();  // 在线客户端列表
int activeSessions = server.getActiveSessionCount();  // 活跃隧道数

// 监听连接事件
server.onConnect(clientId -> log.info("上线: {}", clientId));
server.onDisconnect(clientId -> log.info("下线: {}", clientId));

// 停止
server.stop();

3. Provider（服务提供方）

3.1 暴露固定服务

SipClient client = SipClient.tcp("tcp://server:19460")
        .token("my-secret")
        .connect();

// 链式 DSL，一行一个服务
client.service("web").to("127.0.0.1", 8080);
client.service("ssh").to("127.0.0.1", 22);
client.service("mysql").to("192.168.1.200", 3306);
client.service("redis").to("127.0.0.1", 6379);

// 等价于编程式
new SipTunnelService(client, "web", "127.0.0.1", 8080).start();

3.2 通配模式（暴露整台机器）

// 通配模式：visitor 可访问 provider 可达的任何内网目标
// 白名单限制只能访问 192.168.x.x 和 10.x.x.x
new SipTunnelService(client, "*", "127.0.0.1", 0,
        List.of("192.168.", "10.")).start();

// 不限制白名单（谨慎使用）
new SipTunnelService(client, "*", "127.0.0.1", 0).start();
通配安全：通配模式暴露整台机器，建议配置 allow 白名单限制可访问网段。

3.3 高级配置

// 端到端加密 + 多路复用
SipClient client = SipClient.tcp("tcp://server:19460")
        .token("my-secret")
        .encrypt(true)     // 客户端侧加密，服务端仅桥接密文
        .mux(true)         // 单连接承载所有隧道，减少连接数
        .connect();

// 重连自动恢复服务注册
client.onReconnect(() -> {
    client.service("web").to("127.0.0.1", 8080);
    client.service("ssh").to("127.0.0.1", 22);
});

4. Visitor（访问方）

4.1 端口映射（每个服务一个端口）

SipClient client = SipClient.tcp("tcp://server:19460")
        .token("my-secret").connect();

// 链式 DSL
client.tunnel("web").listen(18080);       // localhost:18080  → 对端 web
client.tunnel("ssh").listen(10022);       // localhost:10022  → 对端 ssh
client.tunnel("mysql").listen(13306);     // localhost:13306  → 对端 mysql

// 指定监听地址
client.tunnel("web").listen("0.0.0.0", 8080);

// 通配模式：直接指定目标 host:port
client.tunnel("192.168.1.100:3389").listen(13389);  // 远程桌面
client.tunnel("10.0.0.5:22").listen(10022);         // SSH

4.2 SOCKS5 代理（一个端口通所有服务，推荐）

SipClient client = SipClient.tcp("tcp://server:19460")
        .token("my-secret").connect();

SipSocks5Proxy proxy = client.socks5(1080);
// 三方软件配 SOCKS5 代理 localhost:1080
// 目标域名 = 服务名，自动路由到对应隧道
软件配置方式
浏览器设置 SOCKS5 代理 127.0.0.1:1080
SSHssh -o ProxyCommand='nc -X 5 -x 127.0.0.1:1080 %h %p' user@web
数据库客户端网络代理 SOCKS5 127.0.0.1:1080，目标 mysql:3306
终端export ALL_PROXY=socks5://127.0.0.1:1080

4.3 编程式隧道控制

// 手动打开隧道（不监听端口，直接获取会话读写）
SipTunnelSession session = client.openTunnel("web");

session.sendBytes(data);                                  // 发送数据
session.onBytes(bytes -> handle(bytes));                  // 接收数据
session.isOpen();                                         // 状态检查
session.close();                                          // 关闭隧道

// 异步打开
CompletableFuture<SipTunnelSession> future = client.openTunnelAsync("web");
future.thenAccept(session -> session.onBytes(this::handle));

provider.service("rdp").to("192.168.1.100", 3389);

// 测试隧道通信
@Test
void testTunnel() throws Exception {
    SipServer server = new SipServer();
    server.start();
    int port = server.getPort();
    int echoPort = freePort();

    // 启动回显服务
    ServerSocket echo = new ServerSocket(echoPort);
    Thread.ofVirtual().start(() -> {
        while (true) {
            Socket s = echo.accept();
            Thread.ofVirtual().start(() -> {
                s.getInputStream().transferTo(s.getOutputStream());
            });
        }
    });

    // Provider 暴露 echo 服务
    SipClient provider = SipClient.tcp("tcp://127.0.0.1:" + port)
            .token("token").connect();
    provider.service("echo").to("127.0.0.1", echoPort);

    // Visitor 端口映射
    SipClient visitor = SipClient.tcp("tcp://127.0.0.1:" + port)
            .token("token").connect();
    visitor.tunnel("echo").listen(echoPort + 1);
    Thread.sleep(500);

    // 验证数据透传
    Socket test = new Socket("127.0.0.1", echoPort + 1);
    test.getOutputStream().write("hello".getBytes());
    byte[] buf = new byte[1024];
    int n = test.getInputStream().read(buf);
    assertEquals("hello", new String(buf, 0, n));
    test.close();
    provider.close();
    visitor.close();
    server.stop();
}

8.2 基准测试代码

// 吞吐量测试（单隧道，64KB 数据包）
@Test
void testThroughput() {
    SipTunnelSession session = setupTunnel();
    byte[] data = new byte[64 * 1024];
    new Random().nextBytes(data);
    int totalPackets = 1000;
    long start = System.nanoTime();
    for (int i = 0; i < totalPackets; i++) {
        session.sendBytes(data);
    }
    long elapsed = System.nanoTime() - start;
    double mbps = (totalPackets * data.length * 8.0) / elapsed;
    log.info("吞吐量: {} Mbps", String.format("%.2f", mbps * 1_000_000_000));
}

// 并发隧道建立测试
@Test
void testConcurrentTunnels() {
    int tunnelCount = 100;
    ExecutorService pool = Executors.newVirtualThreadPerTaskExecutor();
    List<CompletableFuture<Void>> futures = new ArrayList<>();
    long start = System.nanoTime();
    for (int i = 0; i < tunnelCount; i++) {
        futures.add(CompletableFuture.runAsync(() -> {
            SipTunnelSession session = openTunnel();
            session.sendBytes("ping".getBytes());
            session.close();
        }, pool));
    }
    CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
    long elapsed = System.nanoTime() - start;
    log.info("{} 个隧道耗时: {} ms", tunnelCount, elapsed / 1_000_000);
}

// 延迟测试（RTT）
@Test
void testLatency() throws Exception {
    SipTunnelSession session = setupTunnel();
    CountDownLatch latch = new CountDownLatch(1);
    long[] rtt = new long[1];
    session.onBytes(data -> {
        rtt[0] = System.nanoTime() - rtt[0];
        latch.countDown();
    });
    rtt[0] = System.nanoTime();
    session.sendBytes("ping".getBytes());
    latch.await(5, TimeUnit.SECONDS);
    log.info("RTT: {} us", rtt[0] / 1000);
}

9. 注意事项

注意点说明
服务名唯一tunnelServices 是 Map<serviceName, clientId>，同名服务覆盖
通配安全通配模式暴露整机，建议 allow 白名单限制网段
直连前提要求双方有公网 IP 或同一内网，否则自动走中继
加密一致encrypt(true) 时两侧 token 必须一致（派生 AES-256 密钥）
复用一致mux(true) 时两侧必须同时开启
连接超时默认 5s，网络差时可调大
心跳保活默认 15s 一次 PING，NAT 映射不丢
自动重连网络抖动自动重连，onReconnect 回调恢复服务注册
最佳实践：新项目建议直接使用 socks5(1080) 模式，一个端口通所有服务，三方软件配置一次即可。
