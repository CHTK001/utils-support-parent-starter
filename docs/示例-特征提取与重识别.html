PersonReidExample ReID

行人重识别：提取人物外观特征，跨摄像头比对同一人。

PersonReidModel model = new PersonReidModel("reid_model.onnx");

// 提取特征
float[] feat1 = model.extract(image1);
float[] feat2 = model.extract(image2);

// 比对
float sim = cosine(feat1, feat2);
System.out.printf("匹配度: %.4f %s%n", sim, sim > 0.7 ? "同一人" : "不同人");
