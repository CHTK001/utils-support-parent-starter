核心 API 形态

var runner = TaskRunner.of("demo")
        .timeout(Duration.ofSeconds(10))          // 全局默认单任务超时
        .retry(3)                                  // 全局默认重试次数
        .policy(CompletionPolicy.successRate(0.8)) // 必填完成策略
        .task("a", ctx -> fetchA())
        .task("b", ctx -> merge(ctx))
            .afterNode("a")                        // 控制流依赖
            .dependsNode("a")                      // 数据依赖（前置结果非 null 校验）
            .failureThreshold(3).waitDuration(10_000)
            .circuitBreaker()                      // 熔断开关（委托 CircuitBreakerFlow）
            .fallback(ctx -> cachedValue());       // 降级兜底

runner.executeSync(input);   // 同步
runner.execute(input);       // 异步 CompletableFuture<RunResult>
runner.executeReactor();     // Mono<RunResult>
runner.watch();              // Flux<RunnerEvent>

实现要点备注

  • 调度引擎：StructuredRunnerProvider（@Spi("structured")）— Kahn 拓扑分层 + Java 25 StructuredTaskScope.open(Joiner.allUntil(...)) 层内并行，达到策略目标或不可能达标时提前取消剩余 fork。
  • 单节点链路（外→内）：熔断(CircuitBreakerFlow) → 超时(嵌套 scope withTimeout) → 重试(指数退避 200ms→2s 封顶) → 数据依赖校验 → 业务函数 → fallback 兜底。
  • 被提前取消/级联跳过的节点记为 SKIPPED 且不计入完成策略分母。
  • 熔断状态按节点 ID 跨多次 run 持久（InMemoryCircuitBreakerProvider 缓存）。
