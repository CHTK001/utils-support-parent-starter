一、引擎架构与路由策略

引擎驱动R2DBCJDBC 路由说明
H2h2-2.x✅ r2dbc-h2R2DBC 直连内嵌内存库，零配置，真正非阻塞
MySQLmysql-connector-j⚠️ r2dbc-mysql强制 JDBCr2dbc-mysql 的 getRowsUpdated 有 CCE 问题，已由 needsJdbcPath() 强制走 JDBC
PostgreSQLpostgresql-42.7.3✅ r2dbc-postgresqlR2DBC 直连官方 R2DBC 驱动，真正非阻塞
SQL Servermssql-jdbc-12.6.1⚠️ r2dbc-mssql强制 JDBCr2dbc-mssql 的 SimpleMssqlStatement 不支持参数绑定，已由 needsJdbcPath() 强制走 JDBC
SQL Server (jTDS)jTDS-1.3.1❌ 无JDBC only老版本 SQL Server 2000/2005 兼容驱动，伪响应式（boundedElastic）
SQLitesqlite-jdbc❌ 无JDBC only内嵌文件库，伪响应式
关键结论：MySQL 和 SQL Server 的 R2DBC 驱动存在已知缺陷（占位符绑定/批量更新）， 核心引擎 JdbcReactorEngine.needsJdbcPath() 已强制将其路由到 JDBC 路径。 jTDS 等老版本驱动本身无 R2DBC 实现，只能走 JDBC 伪响应式。

void h2_write_throughput() {
    H2Engine engine = new H2Engine();
    engine.addDataSource("default", "jdbc:h2:mem:bench;DB_CLOSE_DELAY=-1");
    engine.execute("CREATE TABLE bench (id BIGINT PRIMARY KEY, name VARCHAR(64), val DOUBLE)");
    long start = System.nanoTime();
    for (int i = 0; i < COUNT; i++) {
        engine.execute("INSERT INTO bench(id, name, val) VALUES(?,?,?)", (long)i, "name_"+i, (double)i);
    }
    double ops = COUNT * 1e9 / (System.nanoTime() - start);
    System.out.printf("[H2] 写入吞吐: %,d ops/s%n", (long)ops);
}

四、SQL 自动降级机制

// JdbcReactorEngine.java:692-707
private boolean needsJdbcPath(String name) {
    String url = jdbcUrls.get(name);
    if (url == null) return false;
    String lowerUrl = url.toLowerCase();
    // 已知 R2DBC 驱动缺陷的协议强制 JDBC
    if (lowerUrl.startsWith("jdbc:mysql:")
            || lowerUrl.startsWith("jdbc:mariadb:")
            || lowerUrl.startsWith("jdbc:sqlserver:")) {
        return true;  // ← 直接走 JDBC，不走 R2DBC
    }
    return !r2dbcFactories.containsKey(name);  // 无 R2DBC 工厂时也走 JDBC
}
数据库R2DBC 驱动状态实际执行路径是否自动降级
H2✅ r2dbc-h2R2DBC 直连否（原生支持）
PostgreSQL✅ r2dbc-postgresqlR2DBC 直连否（原生支持）
MySQL⚠️ r2dbc-mysql (有缺陷)JDBC 强制✅ 主动降级（规避 getRowsUpdated CCE）
SQL Server⚠️ r2dbc-mssql (有缺陷)JDBC 强制✅ 主动降级（规避 SimpleMssqlStatement 参数绑定问题）
SQLite❌ 无驱动JDBC only✅ 自然降级（无 R2DBC 工厂）
jTDS (Legacy)❌ 无驱动JDBC only✅ 自然降级
回答用户问题：SQL 会自动降级到 JDBC 路径。 MySQL 和 SQL Server 虽然注册了 R2DBC 连接工厂，但 needsJdbcPath() 会强制路由到 JDBC。 老版本 SQL Server（jTDS）没有 R2DBC 驱动，只能走 JDBC 伪响应式（boundedElastic 调度阻塞调用）。
