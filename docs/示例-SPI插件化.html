SPI 插件化

SPI 机制：项目的核心设计——通过 Java SPI + 自定义注解实现插件化，支持多实现动态切换。

基础 SPI

HelloService / HelloServiceImpl 基础

最简单的 SPI 示例：定义接口 → 实现 → 注册 → 调用。

// 1. 定义接口
public interface HelloService {
    String sayHello(String name);
}

// 2. 实现并注册
@Spi("default")
@SpiDescribe("默认实现")
public class HelloServiceImpl implements HelloService {
    @Override public String sayHello(String name) {
        return "Hello, " + name;
    }
}

// 3. META-INF/extensions/com.chua.example.spi.HelloService
//    com.chua.example.spi.HelloServiceImpl

// 4. 调用
HelloService service = ServiceProvider.get(HelloService.class, "default");
String msg = service.sayHello("World");
