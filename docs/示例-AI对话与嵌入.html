通义千问对话

QwenProxyExample chat 零成本

通过 Playwright 驱动 Qwen 网页版，免费多轮对话、图像生成与视频生成。

java QwenProxyExample --cookie="token=eyJ..." --module=all
java QwenProxyExample --cookie="token=xxx" --module=chat
java QwenProxyExample --cookie="token=xxx" --module=image

核心 API（链式）

ChatClient client = ChatClient.create(
    ChatClientSetting.builder()
        .provider("qwen-proxy")
        .appKey("token=你的cookie")
        .model("qwen3.8-max")
        .build());

// 多轮对话（自动维护上下文）
String reply  = client.chatSync("我叫张三");
String recall = client.chatSync("我刚才说了什么？");

// 图像生成
ImageGenerationResult img = client.generateImage()
    .prompt("一只柯基犬在阳光下微笑")
    .ratio("16:9")
    .generate();

client.close();

文本嵌入 Embedding

BgeEmbeddingExample / MiniLmEmbeddingExample 离线

完全离线文本向量化，模型随 jar 自动解压。

try (EmbeddingClient client = EmbeddingClient.create(
        EmbeddingClientSetting.builder().provider("bge").build())) {
    String[] docs = {"你好世界", "今天天气很好", "人工智能正在改变世界"};
    float[][] vectors = client.model("bge-small-zh").embeddingBatch(docs);

    float sim = cosine(vectors[0], vectors[1]);
    System.out.println("相似度: " + sim);
}

语音识别与合成

WhisperAudioExample STT

WhisperClient whisper = new WhisperClient(WhisperModel.LARGE_V3);
AudioTranscript transcript = whisper.transcribe("audio.wav");
transcript.getSegments().forEach(s ->
    System.out.printf("[%.2fs-%.2fs] %s%n", s.getStart(), s.getEnd(), s.getText()));

视觉 AI

YoloWorldExample 开放词汇

YOLO-World 无需预训练类别即可检测任意物体。

YoloWorldDetector detector = new YoloWorldDetector("damoyolo_visdrone.onnx");
List<DetectedObject> objects = detector.detect("image.jpg",
    new String[]{"person", "car", "building"});
objects.forEach(obj -> System.out.printf("%s: %.2f%n", obj.getLabel(), obj.getConfidence()));
