OCR 体系：基于 PaddleOCR v6，支持中英文识别、方向角校正、批量处理、质量门控。

基础 OCR

OcrPipelineExample 基础

PaddleOCR v6 完整流水线：图像预处理 → 检测 → 识别 → 后处理。

OcrPipeline pipeline = OcrPipeline.builder()
    .detModel("ch_PP-OCRv4_det_infer.onnx")
    .recModel("ch_PP-OCRv4_rec_infer.onnx")
    .angleModel("ch_ppocr_mobile_v2.0_cls_infer.onnx")
    .build();

List<OcrResult> results = pipeline.recognize("document.jpg");
for (OcrResult r : results) {
    System.out.printf("[%d,%d,%d,%d] %.2f: %s%n",
        r.getX(), r.getY(), r.getW(), r.getH(), r.getConfidence(), r.getText());
}

质量门控

OcrQualityGateDiag 质量

OCR 质量门控诊断：自动过滤低置信度、模糊、旋转角度过大的识别结果。

OcrEnhanceOnlyDiag / OcrDeskewCompareAll

图像增强预处理：去噪、对比度增强、自动校偏，提升识别准确率。

角度校正

OcrAngleDiag / OcrRotateCompare

多角度 OCR 测试：0°/90°/180°/270° 旋转识别对比，自动选择最优角度。

批量处理

OcrBatchTest

批量 OCR 性能测试：支持多线程并行处理多张图片，含吞吐量和延迟统计。

诊断工具

OcrDetDiag / OcrRecShapeDiag / OcrCropDiag / OcrUnclearDiag

OCR 各阶段诊断工具：检测框分析、识别形状分析、裁剪效果对比、模糊图诊断。
