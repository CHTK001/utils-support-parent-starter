# utils-support-doubao-starter

豆包/火山引擎集成模块：Ark 大模型对话

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-doubao-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `DoubaoChatClient` | 豆包/火山引擎大模型对话客户端 基于火山引擎 Ark 大模型 API 的 实现，通过 HTTP 协议 调用豆包（Doubao）系列模型的对话接口。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
