# utils-support-qq-starter

QQ开放平台 Bot 客户端集成

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-qq-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `QqBotClient` | QQ Bot 客户端，实现 接口。 |
| `QqBotClientFactory` | QQ Bot 客户端工厂（SPI 实现）。 平台名称为 。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
