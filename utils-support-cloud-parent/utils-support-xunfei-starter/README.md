# utils-support-xunfei-starter

讯飞星火大模型集成模块

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-xunfei-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `XunfeiChatClient` | 讯飞星火大模型对话客户端 基于讯飞星火认知大模型 API 的 实现，通过 HTTP 协议 调用星火大模型的对话接口，支持星火 3.0、4.0 等版本。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
