# utils-support-openai-starter

OpenAI 大模型集成模块

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-openai-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `OpenAiImageClient` | OpenAiImageClient |
| `OpenAiChatClient` | OpenAI 大模型对话客户端 基于 OpenAI Java SDK 的 实现，支持 OpenAI 兼容接口的 所有服务商（如 OpenAI、SiliconFl |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
