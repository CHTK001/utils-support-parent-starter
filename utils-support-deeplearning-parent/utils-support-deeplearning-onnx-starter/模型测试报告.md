## SAM2-tiny 说明

SAM2 是交互式分割模型，需要点提示（point_coords/point_labels）或框提示：
- Encoder 输入 [1,3,1024,1024] → 输出 3 级特征图
- Decoder 输入特征图 + 点提示 → 输出 [1,1,256,256] 掩码
- 适合人机交互场景（如 Selectable Segmentation），不适合无提示的批量黑盒测试
- 实现方案：需创建 Sam2Pipeline 类，组合 encoder+decoder 两步推理

## YOLO-World 零样本检测修复（v4.0.0.42）

### 问题根因（三层叠加）

1. **假 txt_feats**：旧 translator 用 hash 锚位编码伪造 CLIP 文本特征 → 检测头 RepGlpn 无法产生有效预测，bbox 全 0、logits 恒定 ~640
2. **输出布局误读**：ultralytics 导出为 `[1, 4+nc, 8400]`，**前 4 通道是 bbox(cx,cy,w,h)**，后 nc 通道才是类别；旧代码按"类别在前、bbox 在后"解码全错
3. **重复 sigmoid**：ultralytics 8.4 导出的类别通道已是 sigmoid 后的概率，旧代码再激活一次导致背景噪声 ~0.002 变成 0.50 假阳性满天飞

### 修复方案

- 放弃运行时 txt_feats 输入方案（mobileclip text_model_quantized.onnx 为 0 字节占位符，无真实文本编码器）
- 用 ultralytics 官方流程重新导出：`yolov8s-worldv2.pt` 预训练权重中 COCO-80 的 CLIP 文本特征已烘焙进检测头，输入仅 `images [1,3,640,640]`
- 注意：`set_classes(自定义类别)` 后导出在 torch 2.13+CPU 下异常（bbox 全 0），COCO-80 内置特征正常；`candidates` 参数改为 COCO-80 过滤白名单保持 API 兼容
- 新模块 `utils-support-models-onnx-yoloworld-s`：51.4MB ONNX 嵌入 jar（md5 校验一致）
- 重写 `YoloWorldDetectorTranslator`：letterbox(114填充)→CHW→[1,3,640,640]；解码 bbox 前 4 通道 + 类别概率直读 + NMS(iou=0.5) + letterbox 反算原图坐标
- 诊断开关 `-Dyoloworld.probe=true` 输出原始张量统计

### 阈值策略（误检/漏检平衡）

- 默认 `threshold=0.30`：COCO-80 通用模型对非典型目标置信度天然偏低
- **全图噪声规则**：置信度 <0.45 且框面积占比 >70% 的框视为背景噪声丢弃
  - 动机：文字类图片易被弱置信度误检为 laptop/person 且框覆盖全图（如 led文字.jpg 的 laptop 0.34 占 74%）
  - 真实目标不受影响：truck.jpg 卡车 0.35 占 43%、人像特写全图框 conf≥0.9 走高分豁免
