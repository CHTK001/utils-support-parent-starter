# ONNX 模型测试报告

> 更新日期：2026-08-16
> **测试环境（升级后）：Windows, JDK 25, DJL 0.36.0, ONNX Runtime 1.21.1, OpenCV 4.9.0-0, CPU**
> 测试方式：统一 SPI 门面 Example（XxxClientExample），切换 provider + model 实测
> 图像预处理：**统一 OpenCV**（替代 DJL NDArray / Java2D）
> GPU：DJL 0.36.0 onnxruntime-engine 原生支持 CUDA（需 onnxruntime_gpu + Device.gpu()）

> **本报告基于 DJL 0.36.0 重新测试，旧版本（0.27）数据已重置。**

### 升级说明

- **DJL 0.27 → 0.36.0**（onnxruntime-engine、api、tokenizers、pytorch-engine 同步升级）
- **ONNX Runtime 1.21.0 → 1.21.1**
- **OpenCV 4.9.0-0**（图像预处理统一，替代 DJL NDArray / Java2D）
- **GPU 支持**：DJL 0.36.0 onnxruntime-engine 原生支持 CUDA（`SessionOptions.addCUDA()`），
  需 `onnxruntime_gpu:1.21.1` 替换 CPU 版 + `Device.gpu()`；当前环境用 CPU
- **新业务接口**：`ImageCaptioning`（图像描述）、`MattingService`（抠图）
- 走 DJL 引擎的模型（mobileclip/dinov2/modnet）→ OpenCV 预处理 + `create()` 喂入 djl-onnx
