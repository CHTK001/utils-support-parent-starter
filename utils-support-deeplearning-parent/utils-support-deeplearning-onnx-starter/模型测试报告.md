### 6.1 YOLO-World 嵌入式零样本检测

> 2026-08-19 新增。YOLO-World 是**真正的开放词表（零样本）检测模型**：输入任意文本类别（中/英文混合，如 `"人,汽车,穿红衣服的人"`），输出检测框坐标 + 类别 + 置信度，**无需针对目标类别训练**。
> 与 COCO 固定 80 类检测不同，候选类别完全由用户运行时指定。

**体积对比（200MB 内嵌入式可选）**：

| 模型 | 体积 | 嵌入式适用 |
|------|------|-----------|
| yolov8s-world | ~40MB | ✅ 首选 |
| yolov8m-world | ~70MB | ✅ |
| yolov8l-world | ~130MB | ✅ |
| MobileCLIP S0 | ~50MB | ✅（仅分类无坐标） |
| grounding-dino | ~230MB | ⚠️ 超限 |
| owlv2 | ~600MB | ❌ |

**模型文件获取**：首次运行自动从 downloadUrl 下载到缓存（`%TEMP%\chua-dl-models`），主地址失败自动切换 hf-mirror 镜像。

**输入输出**：
- 输入：图片 + `candidates` 参数（文本类别列表，中英文混合，支持逗号/中文逗号/顿号分隔）
- 输出：`DetectedObjects`（类别名 + 归一化边界框 + 置信度）

**translator 源码**：`onnx/yoloworld/YoloWorldDetectorTranslator`，letterbox resize（640×640，灰蓝填充）+ normalize，HuggingFaceTokenizer 预编码候选类别（"object: label" prompt），端到端输出解析 pred_boxes + pred_scores，内置 NMS。

**示例**：`com.chua.example.ai.vision.YoloWorldExample`（对 `D:\images` 下图片做中英文候选检测）。

### 14.2a Seq2Seq 文本生成实现（嵌入优先 + modelscope 下载）

> 2026-08-19 新增 ORT 原生 encoder-decoder 自回归实现，落地模型：
> **t5-seq2seq**（T5-small 英文摘要/生成/翻译）、**mt5-seq2seq**（mT5-small 中文）、**mt5-base-seq2seq**（mT5-base 中文）。
> 源码：`onnx/seq2seq/T5Seq2SeqOrtTranslator`（基类）+ `Mt5Seq2SeqOrtTranslator` / `Mt5BaseSeq2SeqOrtTranslator`（子类）
> + `Seq2SeqModelResources` + `Seq2SeqModelDefinition`。
> 测试：`onnx/example/Seq2SeqExample`（main）与 `onnx/example/Seq2SeqTranslationTest`（JUnit）。

**模型文件获取优先级（`Seq2SeqModelResources.resolve`）**：

1. **嵌入式优先**：classpath jar 内存在 `nlp/seq2seq/{modelId}/` 资源目录时，经
   `NativeLoader` 解压到 `deeplearning.model.cache-dir` 下 `{modelId}/`（MD5 增量，缺省
   `%TEMP%/chua-dl-models`）；
2. **本地缓存直读**：缓存目录四文件齐全则直接使用；
3. **modelscope 下载**：按 `Seq2SeqModelDefinition` 清单从
   `https://www.modelscope.cn/models/{repo}/resolve/master/...` 补齐
   `encoder / decoder / decoder_with_past / tokenizer.json` 四文件。

**OR 原生自回归生成（`T5Seq2SeqOrtTranslator`，子类 `Mt5Seq2SeqOrtTranslator` / `Mt5BaseSeq2SeqOrtTranslator`）**：

- encoder：`input_ids + attention_mask → last_hidden_state`；
- decoder 首步：`input_ids(decoder_start=0) + encoder_attention_mask + encoder_hidden_states → logits + present.*`；
- decoder_with_past 循环：`input_ids(上一步 token) + past_key_values.*.decoder/encoder.key/value → logits + present.*`；
- 贪心解码 + repetition penalty 1.3 + 三重重复截断 + EOS(1) 停止；注意力头数/维度从输出 shape 动态解析
  （兼容 t5/mt5 6~12 头多种配置）；`minNewTokens=10`（默认，达到前禁 EOS，避免摘要过短）；
  后处理剔除 `<extra_id_*>` 占位 token；任务前缀可经 `T5Seq2SeqOrtTranslator.setTaskPrefix` 配置
  （摘要用 `summarize: `），最小/最大长度可分别经 `setMinNewTokens` / `setMaxNewTokens` 调整。

> **精度注记（实测复现）**：
> - mT5 的 **int8 动态量化会使中文生成严重退化**（编码器量化输出 `<extra_id_0>`、解码器量化输出模板噪声），
>   故 `MT5_SMALL` / `MT5_BASE` 均改用 **全 fp16**（small：294+562+556MB；base：554+995+967MB）。
> - **中文真实语料评估**（见下表）：即使全 fp16，mT5-small / mT5-base 在**正式/新闻等书面语料上仍退化**，
>   输出"网页模板式"碎片；仅在**口语化、短文本**场景可用。**英文摘要（T5-small / T5-base）质量良好**。
>   结论：mT5 多语言模型未学习中文摘要，本地仅 T5 英文系列可靠；中文正式文本暂无可用的纯 ONNX 模型。

**注册模型**：`t5-seq2seq`（T5-small 英文）、`t5-base-seq2seq`（T5-base 英文，质量更好）、
`mt5-seq2seq`（mT5-small 中文，质量有限）、`mt5-base-seq2seq`（mT5-base 中文，质量有限）。

## 20. 图片清晰度检测门面

> 2026-08-19 新增。定义统一清晰度评估门面（单一职责，仅评估不修复），OpenCV / ONNX 双后端 + SPI 可扩展。

### 门面接口（deeplearning-starter）

| 接口 | 返回值 | 配置 | 说明 |
|------|--------|------|------|
| `ImageClarityDetector` | `ImageQualityInfo`（模糊度/亮度/对比度/是否清晰） | `blurThreshold` / `modelPath` / `device` | 图片清晰度评估 |
| `FaceClarityDetector` | `FaceQualityInfo`（人脸数/尺寸/模糊度/亮度） | `blurThreshold` / `minFaceRatio` / `modelPath` / `device` | 人脸清晰度评估 |

**设计原则**：专注清晰度评估单一职责，不内嵌修复逻辑；图片不清晰时由调用方按需调用 `ImageEnhancer`（naf-net 去模糊 / real-esrgan / text-bsr 超分）。

### SPI 实现

| 后端 | 类 | 默认模型 | 嵌入式 |
|------|-----|---------|--------|
| opencv | `OpencvImageClarityDetector` | `opencv-image-quality`（Laplacian 方差） | ✅ 零模型文件 |
| opencv | `OpencvFaceClarityDetector` | `opencv-face-quality`（Haar 级联内嵌 jar） | ✅ 零下载 |
| onnx | `OnnxImageClarityDetector` | `nima`（NIMA 图像质量评分） | ⚠️ 需下载模型 |
| onnx | `OnnxFaceClarityDetector` | 需显式 `.model()` 指定 | - |

**用法**：
```java
// 嵌入式（OpenCV 纯算法，无模型下载）
ImageQualityInfo info = ImageClarityDetector.create("opencv", "")
        .blurThreshold(100.0)
        .assess(imageBytes);
if (!info.sharpnessOk()) {
    // 不清晰 → 按需调用增强门面修复
    byte[] fixed = ImageEnhancer.create("naf-net").enhance(imageBytes);
}
```

**能力映射**：`ModelCapabilities` 增加 `ImageClarityDetector → IMAGE_QUALITY`、`FaceClarityDetector → FACE_QUALITY`。

**示例**：`com.chua.example.image.ImageClarityDetectorExample`（对 `D:\images` 下图片做图片/人脸清晰度评估）。

### 特征维度覆盖（2026-08-20）

嵌入式已打包 384 / 512 维（零联网可测），更多维度通过 downloadUrl 自动下载：

- **文本嵌入 768/1024**：bge-base-zh/en（768）、bge-m3（1024）— BgeTextFeatureTranslator 相同译器，注册已通过 15/15
- **图片特征 768/1024/2048**：dino-v2-base（768）、dino-v2-large（1024）、resnet50（2048）— translator 复用同逻辑
- **实测方式**：`FeatureDimensionExample`（注册验证）+ `FeatureDimensionInferenceExample`（合成图 + 文本样本，验证 vec.length == 预期维度 + L2 范数）
