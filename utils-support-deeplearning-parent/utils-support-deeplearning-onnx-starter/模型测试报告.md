## SAM2-tiny 说明

SAM2 是交互式分割模型，需要点提示（point_coords/point_labels）或框提示：
- Encoder 输入 [1,3,1024,1024] → 输出 3 级特征图
- Decoder 输入特征图 + 点提示 → 输出 [1,1,256,256] 掩码
- 适合人机交互场景（如 Selectable Segmentation），不适合无提示的批量黑盒测试
- 实现方案：需创建 Sam2Pipeline 类，组合 encoder+decoder 两步推理

## 修复内容

1. **MattingTranslator 重写**：移除 NDImageUtils.resize（ORT 引擎不支持），改用 AWT Graphics2D 手动 resize + 像素级归一化
2. **新增 IsnetSegTranslator**：专门处理 ISNet/Anime 类 1024×1024 输入、无 ImageNet 归一化的分割模型
3. **新增 U2netSegTranslator**：专门处理 U2Net/U2Netp/Human 类 320×320 输入的分割模型
4. **新增 ClothSegTranslator**：处理 U2Net Cloth 768×768 输入、4 通道 argmax 输出
5. **OnnxModelRegistrar 更新**：6 个新分割模型注册使用对应 Translator
6. **MattingService.toBufferedImage 修复**：支持 byte[] 输入（adaptOutput 已将 Image 转为 byte[] PNG）
