# utils-support-docker-starter

Docker 客户端集成，基于 docker-java SDK

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-docker-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `DockerClient` | Docker 客户端，基于 docker-java SDK，支持链式调用。 封装 docker-java SDK，提供简化的链式 API。 使用方式 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
