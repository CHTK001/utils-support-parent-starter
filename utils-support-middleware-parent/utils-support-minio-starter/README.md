# utils-support-minio-starter

MinIO 对象存储集成模块，支持本地测试和 S3 兼容存储

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-minio-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `MinioFileStorage` | MinIO 文件存储实现。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
