# utils-support-armeria-starter

Armeria HTTP 服务器实现

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-armeria-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `ArmeriaHttpServer` | 基于 Armeria 的 HTTP 服务器实现。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
