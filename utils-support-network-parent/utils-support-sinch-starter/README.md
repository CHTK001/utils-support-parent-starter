# utils-support-sinch-starter

Sinch 语音电话集成

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-sinch-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `SinchVoiceCall` | Sinch 语音电话实现 (SPI: `sinch`) |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
