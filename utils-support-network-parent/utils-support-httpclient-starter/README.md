# utils-support-httpclient-starter

Apache HttpClient5 HTTP 客户端执行器 SPI 实现

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-httpclient-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `HttpClient5Executor` | 基于 Apache HttpClient5 的 HTTP 客户端执行器 (SPI: `httpclient5`) |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
