# utils-support-html-starter

HTML 文件系统与文档转HTML转换模块

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-html-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `HtmlConvertFileSystem` | 文件转 HTML 转换器。 使用 Aspose.HTML 将 EPUB、SVG、MHTML、Markdown 等格式转换为 HTML，并自动删除水印。 |
| `HtmlWatermarkRemover` | HTML 水印删除工具类。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
