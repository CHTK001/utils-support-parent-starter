# utils-support-qqwry-starter

QQWry 纯真IP数据库查询模块

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-qqwry-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `QqwryIpPosition` | QQWry IP 地理位置查询 SPI 实现。 (SPI: `qqwry`) |
| `QQWryReader` | QQWry 纯真 IP 数据库查询器。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
