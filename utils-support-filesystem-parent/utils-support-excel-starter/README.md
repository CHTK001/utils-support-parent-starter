# utils-support-excel-starter

Excel 文件系统 SPI 实现（基于 Apache POI）

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-excel-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `ExcelFileSystem` | Excel 文件系统 SPI 实现（基于 Apache POI）。 支持 .xlsx / .xls 格式。 (SPI: `excel`) |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
