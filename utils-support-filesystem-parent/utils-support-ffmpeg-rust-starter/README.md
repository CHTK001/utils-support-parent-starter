# utils-support-ffmpeg-rust-starter

基于 Rust JNI 原生实现的 FFmpeg 处理器

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-ffmpeg-rust-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `RustFFmpegBridge` | RustFFmpegBridge |
| `RustFFmpegProcessor` | RustFFmpegProcessor |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
