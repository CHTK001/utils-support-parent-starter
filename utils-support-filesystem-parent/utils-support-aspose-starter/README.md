# utils-support-aspose-starter

基于 Aspose 的文档格式转换模块

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-aspose-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `AsposeExcelFileConvertSystem` | Aspose.Cells 电子表格格式转换器。 |
| `AsposePptFileConvertSystem` | Aspose.Slides 演示文稿格式转换器。 |
| `AsposeWordFileConvertSystem` | Aspose.Words 文档格式转换器。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
