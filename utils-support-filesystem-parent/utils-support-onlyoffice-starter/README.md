# utils-support-onlyoffice-starter

基于 OnlyOffice 的文档格式转换模块

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-onlyoffice-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `OnlyOfficeFileConvertSystem` | OnlyOffice 文档转换器。 (SPI: `onlyoffice`) |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。

---
