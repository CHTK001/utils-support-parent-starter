# utils-support-spider-starter — 爬虫模块设计方案

## 1. 概述

基于 `utils-support-common-starter` 的 SPI 机制，构建一套可插拔、可扩展的通用爬虫框架。

**设计原则：**
- **核心组件 SPI 化** — Fetcher、Parser、Pipeline 通过 `@Spi` 注册，支持运行时动态替换
- **简单组件直接创建** — Scheduler、Deduplicator、Filter、LinkExtractor 在 Builder 中直接实例化，无需 SPI
- **内置默认实现** — 开箱即用，所有组件都有默认实现
- **SPI 名称简洁** — 不使用冒号分隔，如 `"http"`、`"html"`、`"console"`

## 3. SPI 组件清单

| 接口 | SPI 名称 | 职责 | 默认实现 | 依赖 |
|------|----------|------|----------|------|
| `SpiderFetcher` | `"http"` | HTTP 抓取 | `HttpFetcher` (JDK HttpClient) | **无** |
| `SpiderFetcher` | `"playwright"` | 浏览器渲染抓取 | `PlaywrightFetcher` | playwright |
| `SpiderParser` | `"html"` | HTML 解析 | `HtmlParser` (JSoup) | jsoup |
| `SpiderParser` | `"playwright"` | 浏览器渲染解析 | `PlaywrightParser` | playwright |
| `SpiderPipeline` | `"console"` | 控制台输出 | `ConsolePipeline` | **无** |
| `SpiderAiParser` | `"ai"` | AI 智能解析 | —（需独立模块实现） | ChatClient |

## 4. Builder 设计

Builder **只有必要的组件才走 SPI**，其余直接实例化：

```java
// SPI 方式（用于可扩展的核心组件）
Spider.create()
    .fetcher("http")           // SPI — 可选 http / playwright
    .parser("html")            // SPI — 可选 html / playwright
    .pipeline("console")       // SPI — 可选 console / 自定义
    .aiParser("ai", "sk-xxx")  // SPI — AI 增强
    .build();

// 直接实例化（简单组件）
Spider.create()
    .fetcher(new HttpFetcher())
    .scheduler(new FifoScheduler())
    .deduplicator(new MemoryDeduplicator())
    .linkExtractor(linkExtractor)
    .urlFilter(new DomainUrlFilter("example.com"))
    .build();

// 最简方式（全部使用内置默认）
Spider.create()
    .addUrl("https://example.com")
    .run();
```

## 5. 内置默认实现

| 组件 | 默认值 | 说明 |
|------|--------|------|
| Fetcher | `HttpFetcher` | 使用 JDK `java.net.http.HttpClient`，零外部依赖 |
| Parser | `HtmlParser` (JSoup) | 类路径有 jsoup 时自动加载，否则 fallback |
| Pipeline | `ConsolePipeline` | 格式化打印到控制台 |
| Scheduler | `FifoScheduler` | `ConcurrentLinkedQueue` 线程安全 |
| Deduplicator | `MemoryDeduplicator` | 复用 common 的 `@SpiDefault` 实现 |
| LinkExtractor | `HtmlLinkExtractor` (JSoup) | 类路径有 jsoup 时自动加载 |

> **解析器兜底**：当 jsoup 不在类路径时，`HtmlParser` 不会被 SPI 注册
> （通过 `@ConditionalOnClass` 控制），`build()` 会自动跳过 SPi 加载失败并继续工作。
> 用户可手动设置一个基础解析器。

## 6. ChatClient 集成

`SpiderAiParser` 通过 `@Spi("ai")` 注册，接收 `apiKey` 参数初始化 `ChatClient`。
需要单独的实现模块（如 `utils-support-spider-ai-starter`）。

## 7. Playwright 集成

`utils-support-playwright-starter` 提供了两个爬虫组件：

| 类 | SPI 名称 | 用途 |
|---|---|---|
| `PlaywrightFetcher` | `"playwright"` | 浏览器渲染抓取（JS 动态页面） |
| `PlaywrightParser` | `"playwright"` | 浏览器渲染解析（提取渲染后内容） |

使用方法：
```java
Spider.create()
    .addUrl("https://spa-website.com")
    .fetcher("playwright")   // 使用 Playwright 渲染 JS
    .run();
```
