## 5. 运行方式

```bash

mvn test-compile

# 运行视频 SPI 测试
java -cp target/classes;target/test-classes;<classpath> \
  com.chua.common.support.datasearch.example.VideoResourceProviderExample

# 运行音乐 SPI 测试
java -cp target/classes;target/test-classes;<classpath> \
  com.chua.common.support.datasearch.example.MusicSourceProviderExample
```

- 视频 SPI 测试覆盖全部 8 个视频源（B站 / Cldi / 豆瓣 / TMDB / 万欧 / 无极 / 小鸡 / PanSou）

- tencent getTrackDetail 失败原因：QQ音乐播放链接解析逻辑存在运行时异常
- bodian getPlaylistDetail / getTrackDetail 失败原因：远程酷我 API（bd-api.kuwo.cn）当前不可用
