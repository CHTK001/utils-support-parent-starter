# utils-support-quartz-starter

utils-support-quartz-starter module

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-quartz-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `QuartzSchedulerProvider` | 基于 Quartz 的调度器提供者实现 使用 Quartz 提供企业级任务调度能力。 (SPI: `quartz`) |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
