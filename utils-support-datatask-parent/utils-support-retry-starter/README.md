# utils-support-retry-starter

utils-support-retry-starter module

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-retry-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 功能概览

| 类/接口 | 说明 |
|---------|------|
| `GuavaRetryProvider` | 基于 Guava Retrying 的重试提供者实现 使用 Guava Retrying 库提供声明式重试能力。 |

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
